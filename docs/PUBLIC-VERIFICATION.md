# 验证摘要

版本 1.4.0，验证日期 2026-09-07。插件显示名为“API还没挂”。52 项单元与安装检查通过；46 个浏览器场景经全量回归与针对性复验通过。全量运行中两项旧断言仍要求专用连接或旧的原生开关行为，按新版需求修订后复验通过；最终针对连接恢复、原生就绪、配置请求失败与升级迁移的 6 项复验全部通过。

本版重点验证：耐心等待隐藏超时设置且保留原数值；独立模型搜索显示全部 8 个测试模型，选择后更新模型 ID，地址修改后丢弃过时结果；空闲预选只影响下一次正常生成的第一轮，后台静默任务不消耗预选，后续消息和轮次恢复原优先级；生成中切换、停止及手机布局。模型发现不代表生成连通性测试通过。

1.4.0 增加验证：原生 API 列表勾选控制是否优先，备用模式和状态请求不改写原连接设置或模型列表；旧版专用连接迁移；原生配置无效仍能进入备用；无备用节点时原生请求仍可进入插件；临时读取配置失败不会误请求已关闭的原生 API；URL 自动补全和关闭；流式状态显示；旧节点输出上限不再影响酒馆输出设置。

## 已验证环境

- Windows，SillyTavern 1.18.0。
- Node.js 24.19.0 运行酒馆；Node.js 24.12.0 构建与安装。
- Playwright Chromium，桌面与移动视口。
- Bash 安装脚本在 Windows Git Bash 下完成下载、校验、安装，以及校验不符时不写入目标的验证。安装器覆盖 Docker 风格嵌套配置和符号链接保留。
- 没有 Android 真机、Linux 发行版或 Docker 容器运行实测；相关安装文档基于 Termux 工具链和 SillyTavern 官方 Dockerfile/Compose 布局，不声称验证了所有云面板、容器权限或第三方启动器。

## 自动化结果

当前 52 项单元与安装检查和 46 个浏览器场景验证覆盖：

- 节点优先级、逐个切换、循环恢复、停止生成和关闭循环。
- 超时、HTTP 错误、流式断流、完整回复缓冲、错误脱敏。
- Custom、OpenAI、Claude、Google AI Studio 原生连接联动。
- OpenAI 兼容、Claude Messages、Gemini 原生备用协议。
- Claude 温度范围适配、输出长度跟随酒馆、旧节点输出上限不再生效、全局参数保持不变。
- 安装和覆盖升级、设置持久化、聊天切换、群聊、移动界面。
- 诊断导出、后台生成类型、接收确认、正文长度与响应格式分类，以及日志不含模拟 Key 和回复正文。
- 更新包文件白名单、SHA-256 校验、前后端同步替换、备份、写入失败恢复、生成时拒绝更新、管理员权限。
- 浏览器更新按钮的下载失败状态和重启提示使用模拟更新响应验证；文件替换使用隔离安装目录验证，不会对测试用户的真实 API 发起付费请求。
- 正式发布文件通过 GitHub Release 下载入口取得，不依赖匿名 REST API 查询额度。完整包下载后核对 SHA-256；实际更新下载与文件替换在隔离酒馆再次验证。
- 总轮次 3 时严格执行 ABCABCABC；轮次耗尽后结束，不再空转。
- 草稿模型列表查询、草稿连通性测试、测试停止、保存与撤销修改、仅最终失败提示。
- 手动切换取消旧请求，用原请求完成生成并显示在聊天；悬浮窗停止、收起与展开，以及移动视口位置不越界、不遮住底部输入栏。
- 耐心模式接受超过原配置时限的回复，限时模式仍能超时；禁用 HTTP 客户端默认响应头和响应体时限。没有进行数小时挂起或所有代理环境的验证。

真实酒馆浏览器页面配合本地模拟上游验证了失败后自动切换、完整回复显示与聊天保存。账号信息、节点配置、聊天正文和真实供应商诊断记录不随项目分发。官方原生协议使用本地模拟供应商验证，不能据此承诺所有官方模型和账号均兼容。详细日志用于定位问题，并不代表已修复所有导致消息不显示的第三方交互。

## 分发验证

完整安装包包含前端、独立服务端插件和打包后的安装器，不需要安装运行依赖。配置默认没有 API 节点；每位用户需填写自己的地址、模型和密钥。

从仓库 URL 安装只安装前端扩展，配套服务端仍需使用完整安装包安装。源码开发运行 `npm ci`、`npm run build`、`npm test`。浏览器测试还需要隔离的酒馆实例和本地模拟服务，详见 README。
